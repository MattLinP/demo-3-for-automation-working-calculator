# `%` 一律代表「除以 100」

主流計算機（含 Windows 內建）對 `%` 的解讀會隨相鄰運算子改變：`1200 + 5%` 得到 1260（偷偷解讀成 1200 × 1.05），但 `1200 × 5%` 得到 60。同一符號有兩種語意，結果無法預測，也難以寫成測試案例。

本專案刻意放棄這個慣例：`%` 是一個後綴運算子，語意固定為「除以 100」，因此 `1200 + 5%` 等於 **1200.05**。要計算含稅金額請直接寫 `1200 * 1.05`——本專案的核心賣點就是算式可見，把意圖寫清楚是預期用法。

代價是與使用者的肌肉記憶不符。這是知情下的取捨：換得每一條算式都有唯一的數學正解。看到 `1200 + 5%` 不等於 1260 時，那不是 bug。
