# 計算機

一台個人日常使用的計算機:算式是**可見、可編輯的文字**,不是消失在狀態機裡的按鍵。
詞彙見 `CONTEXT.md`,設計決策見 `docs/adr/`。

## 使用

雙擊 `index.html` 就能用 — 不需要 `npm install`,不需要 build(`docs/adr/0001`)。
輸入算式即見即時預覽,Enter 把算式與結果寫成紙帶上的一筆條目。

## 算式語法

| 寫法 | 意思 |
| --- | --- |
| `+` `-` `*` `/` | 四則運算,常規優先序 |
| `(` `)` | 括號 |
| `-x` | 一元負號 |
| `x%` | 後綴,一律代表「x 除以 100」(`docs/adr/0002`) |
| `ans` | 紙帶最後一筆條目的結果 |

結果在數學上精確之處,顯示也應精確,不帶浮點噪音。
